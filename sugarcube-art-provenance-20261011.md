# Sugarcube artwork for Spoonfed

A pet app by Astra. Sugarcube is the pet; Spoonfed is its app.

These are original artwork drafts prepared with OpenAI Codex (GPT-6) on October 11, 2026. They use the character recipe already saved in the local Spoonfed project: a square frosted sherbet-pink sugar cube with raspberry crystal edges, short arms and feet, and an electric chartreuse miniature spoon.

[View the nine-mood sheet](draft-art/spoonfed-sugarcube/sheet-20261011.png). The [manifest](draft-art/spoonfed-sugarcube/manifest-20261011.json) lists all nine transparent 256px frames and source hashes. The [exact prompts](draft-art/spoonfed-sugarcube/prompt-20261011.md) include the initial generation and the correction that aligned the sheet into safe cells.

Built-in imagegen produced this artwork; no separately billed image API or CLI was used. The shared alpha-preserving converter sliced all nine expressions at a common scale. The sheet and frames were inspected for transparency, intact outlines, complete figures, and absence of generated mood symbols.

The art remains a draft pending Astra's approval. This private repository currently contains artwork only. It does not publish the Spoonfed application, restaurant information, user data, runtime integration, or a deployed website. The existing local application was not included in this commit. Registration, the app's pet well, mood wiring, and shared mood stickers remain separate integration work.
